# FPCC

## Installation

### Prerequisites:

- The usual `*nix` utilities: `make`, `wget`, `curl`, `git`,
- `cmake>=3.12`
- a C99/C++17 compiler.
- [Kodiak](https://github.com/nasa/Kodiak.git)
- [Haskell stack](https://docs.haskellstack.org/en/stable/)
  + `curl -sSL https://get.haskellstack.org/ | sh`
- To certify PRECiSA certificates:
  + [PVS version 8.0](http://pvs.csl.sri.com/)
  + [NASA PVS library](https://github.com/nasa/pvslib)

### Building

#### FPCC

```
git submodule update --init --remote --recursive
./setup.sh
# Follow instructions
stack build
```

#### PVS/PRECiSA

This is assuming some working directory (doesn't matter where, here the
example is in the same directory as FPCC).
```
git clone git@github.com:SRI-CSL/PVS.git
cd PVS
git clone http://github.com/nasa/pvslib nasalib
./configure
make
# If you want it somewhere accessible, install. e.g.,
# cp pvs proveit provethem ~/.local/bin
export PVS_LIBRARY_PATH="$(pwd)/nasalib:$PVS_LIBRARY_PATH"
cd -
```

Then, check the proofs of the prerequisite libraries:
```
cd PVS/nasalib
./prove-all
cd -
```

and for PRECiSA

```
cd fpcc/external/PRECiSA/PVS/
export PVS_LIBRARY_PATH="$(pwd):$PVS_LIBRARY_PATH"
provethem
cd -
```

### Building with Nix

The Nix flake provides:

- Packages for `fpcc` (the default), `precisa`, and the
  `kodiak` and `filib` dependencies (`nix build .#<name>`).
- Apps for `fpcc` and `precisa` (`nix run .#<name>`).
- A development shell containing GHC 9.6.7, `stack` (wrapped to use the
  Nix-provided GHC and to find the FILIB and Kodiak libraries correctly),
  `cabal`, `hpack`, `haskell-language-server`, `fourmolu`, `hlint`, a prebuilt
  `precisa`, and C/C++ build tooling (`nix develop`).

PVS is not currently packaged by the flake. To certify proof certificates
generated by PRECiSA, build PVS and the NASA PVS library following the manual
instructions above.

#### Working in the dev shell

```
nix develop # enter the dev shell (or if using direnv, run `direnv allow` the first time)
stack build # build FPCC (setup.sh is not needed)
stack run fpcc -- --input examples/sqroot.c --backend pvs --entry-point sqroot
precisa examples/sqroot.pvs examples/sqroot.input # precisa will be on PATH
```

#### Building and running without entering the shell

```
nix build # build FPCC through Nix
nix run .# -- --input examples/sqroot.c --backend pvs --entry-point sqroot
nix run .#precisa -- examples/sqroot.pvs examples/sqroot.input
```

### Usage

```
stack run fpcc -- --input examples/sqroot.c --backend pvs --entry-point sqroot
```

This will generate a file called `examples/sqroot.pvs`.

You may then generate a PVS certificate to check via `precisa`,
then verify the proof certificate using PVS:

```
precisa examples/sqroot.pvs examples/sqroot.input
pvs -batch examples/sqroot_num_cert.pvs examples/sqroot_real.pvs
```

### Troubleshooting

- The most likely causes of issues are the incorrect linking of Kodiak and
  FILIB. Make sure those are compiled and their environment variables set.

- Another likely cause of issues is the ghc version. While stack should
  handle all this for you, you may also consider using `ghcup` to
  install ghc 9.6.7

- If you cannot find precisa, make sure it is on your path. It
  installs to `$HOME/.cabal/bin`.

- If you see an error
  `dyld[54985]: symbol not found in flat namespace '__ZNSt8ios_base4InitD1Ev'`
  Or something similar, rebuilding Kodiak with GCC seemed to solve the
  issue (not Apple's Clang aliases to GCC)

- `[S-7011] While building package precisa-4.0.4 (scroll up to its section to see the error) using: ...`
  Make sure you have `extra-lib-dirs` at the end of your stack.yaml.
